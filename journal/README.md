# Journal: your proof of work

Everything you produce goes here: GPU measurements, experiment write-ups, paper notes, weekly and monthly reviews. It is the raw material for blog posts, résumé bullets and interview deep dives. Commit it.

```
journal/
  templates/        copy these
  experiments/      YYYY-MM-DD-short-name.md
  papers/           one file per paper
  reviews/          weekly and monthly
```

Templates: [experiment](templates/experiment.md) · [paper notes](templates/paper-notes.md) · [weekly review](templates/weekly-review.md) · [monthly review](templates/monthly-review.md)
