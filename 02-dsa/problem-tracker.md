## How to use

1. After every problem, add a row in the appropriate week section
2. Mark "Solved?" honestly: ✅ (no help), ⚠️ (hint used), ❌ (looked at solution)
3. Set "Re-review by" date 3-7 days later for problems you needed help on
4. Weekly review (every Sunday): scan for problems marked "Re-review" — solve again from scratch
