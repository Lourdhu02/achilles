## The integrated portfolio strategy

Each piece feeds the others:

```
Build flagship project → write blog post → share on LinkedIn → cross-post on X
        ↓                       ↓                  ↓                 ↓
   GitHub README          dev.to / Substack    LinkedIn algo     X/Twitter algo
        ↓                       ↓                  ↓                 ↓
   Profile credibility    Inbound interest    Recruiter inbound  Industry visibility
        ↓                       ↓                  ↓                 ↓
       └────────────── Resume updates ───────────────┘
```

**Rule:** every flagship project produces a blog post, a LinkedIn post, an X thread, and updates to your resume. Don't skip any.

## Time investment

Phase 1-2 (Months 1-8):
- Resume: 20 hours total across 4 rewrites
- GitHub: 10 hours setup + 30 min/week maintenance
- LinkedIn: 5 hours setup + 30 min/week posting
- Blog: 5-10 hours per post; aim for 1/month = 60-120 hours
- Kaggle: 4-8 hours per competition, aim for 4-6 over the year
- Flagship projects: 80-120 hours each

Total: ~400-500 hours across portfolio work. ~30% of your total prep time. Real investment.

---

## What 'good' portfolio signals to recruiters

| Signal | Strong | Weak |
|---|---|---|
| Resume | 1 page, scannable, specific impact | 2+ pages, vague bullets |
| GitHub | 5+ substantive repos with READMEs | scattered toy code |
| LinkedIn | 1k+ followers, engaging content | empty profile |
| Blog | 10+ posts, technical depth | none or 1-2 old posts |
| Kaggle | Expert + recent activity | "Novice" |
| Public talks | 1-2 lightning talks / meetups | none |

You're aiming for "strong" on at least 4 of 6 by Month 12.

---

## What recruiters do when they Google you

1. LinkedIn → profile + recent activity
2. GitHub → pinned repos + contribution graph
3. Resume PDF → if you have one online
4. Maybe: Twitter/X, blog, personal website
5. Maybe: Kaggle, Hugging Face profile

**Spend time building this surface area.** It works while you sleep.
