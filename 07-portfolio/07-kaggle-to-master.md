# Kaggle Path: Expert → Master

You're already a Kaggle Expert. Moving to Master signals real ML competence.

**Honest assessment:** Master is achievable in 12 months IF you commit. But it's expensive in time. Decide if the ROI is worth it for YOUR target roles.

---

## Kaggle tiers (refresher)

- **Novice** → **Contributor** → **Expert** → **Master** → **Grandmaster**

In each of 4 categories: Competitions, Datasets, Notebooks, Discussions.

You're Expert in Notebooks (per resume). Moving to Master in Notebooks requires medals.

---

## Why Kaggle still matters in 2026

- Verifiable ML skill signal (not "I claim I can do ML")
- Builds your "I do ML" inbound profile
- Specific FAANG teams (recommenders, fraud, vision) recruit from Kaggle leaderboards
- Forces you to learn modern modeling techniques quickly
- Excellent material for portfolio + blog posts

### When Kaggle is NOT the highest-leverage activity
- If your target is LLM Engineer at Anthropic / OpenAI — Kaggle is less relevant
- If you're already drowning in DSA + system design — defer Kaggle
- If you're trying to publish or contribute to OSS instead — that may be higher ROI

---

## Decision: should you invest in Kaggle?

### Invest more time IF:
- Target includes recommender / vision / tabular ML companies
- You enjoy competition-style ML work
- You have 5+ hours/week to spare for Kaggle on top of plan

### Invest minimal time IF:
- Target is pure LLM-focused (Anthropic, OpenAI applied)
- You're behind on DSA / system design
- You haven't shipped flagship projects yet

For YOUR profile (GenAI focus, behind on DSA, need to ship flagships): I'd recommend **minimal Kaggle investment** in Phase 1-2, then revisit in Phase 3 if behind.

## Minimum Kaggle activity (recommended for you)

### 1 high-quality competition per quarter (4-6 weeks committed)

Focus: a competition that aligns with your interests / strengths.

Example competitions (Kaggle hosts these regularly):
- **NLP / RAG-style:** "answer questions from documents"
- **Vision:** OCR, classification, detection
- **Tabular:** real-world business problems
- **LLM-related:** prompt engineering, fine-tuning

### What to do per competition

1. **Week 1: Explore + baseline**
   - Understand data
   - Build naive baseline
   - Read top notebooks
   
2. **Week 2-3: Build solid solution**
   - Architecture choices
   - Feature engineering / preprocessing
   - Validation strategy
   
3. **Week 4-5: Iterate**
   - Ensemble
   - Hyperparameter tuning
   - Error analysis
   
4. **Week 6: Submit + write-up**
   - Final submission
   - Public notebook with explanation
   - Blog post

### Time per competition: ~30-50 hours

---

## What to publish

For each competition, publish:

1. **A "starter notebook"** — easy to fork, well-commented, shows approach
2. **A "deep dive notebook"** — your best techniques, modeling choices, results
3. **A discussion post** — your learnings, surprising findings
4. **A blog post** — cross-post your insights

This is how you build Notebook upvotes → medals → Master.
