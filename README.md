Read [`00-START-HERE/01-honest-truth.md`](./00-START-HERE/01-honest-truth.md) first. Short version:

- **League A (Google, Microsoft, Nvidia, Adobe, Apple, Amazon, Meta, Databricks, Atlassian, Stripe India):** With your profile and 15 months of execution, your offer probability is **50-70%** for getting at least one. Realistic. Achievable.
- **League B (Anthropic, OpenAI, Cohere, Hugging Face applied/remote):** **15-25%.** Stretch goals. Possible. Bar is global, not Indian.

**The plan in this repo is optimized for League A with stretch attempts at League B.** League C requires a different operating system; we can talk about pivoting if you want.

## How to use this repo day-to-day

1. **Every Sunday evening (1 hour):** Open `09-the-grind/01-weekly-rituals.md`, plan the week, check the monthly checklist.
2. **Every weekday (2-3 hours):** Execute the phase you're in. Track in your problem tracker / project log.
3. **Every weekend (8+ hours):** Deep work — system design, project building, mock interviews.
4. **End of every month:** Update `09-the-grind/03-month-checklist.md`. Review what you committed to vs. did. Adjust next month.
5. **When you get a callback / interview / offer / rejection:** Update `08-application-strategy/05-tracker.md`. Patterns matter.
