# Online Courses — Curated

3-5 courses to complete (not "consume"). Pick deliberately.

---

## Tier 1: Worth completing fully

### 1. Andrej Karpathy's "Neural Networks: Zero to Hero" (free, YouTube)
- **Format:** 10+ hour-long videos with code
- **Why:** Best free LLM/transformer teaching anywhere
- **When:** Month 2-4
- **Output:** Build nanoGPT from scratch (your transformer implementation exercise)
- **ROI:** Extreme

### 2. Andrew Ng's Deep Learning Specialization (Coursera)
- **Format:** 5 courses, ~5 months at normal pace
- **Why:** Foundational; you may have done parts already (per resume)
- **When:** Months 1-3 as refresher
- **Output:** Final project + cleaner mental models
- **Time:** Speed-run in 6 weeks if already familiar

### 3. fast.ai "Practical Deep Learning for Coders"
- **Format:** Free online; book + video lectures
- **Why:** Code-first, practical, beautiful pedagogy
- **When:** Month 2-3 (complement Andrew Ng)
- **Output:** Build several DL apps
- **Time:** ~40 hours

### 4. Hugging Face NLP Course (free, online)
- **Format:** Modular online curriculum
- **Why:** Best for: transformers library, tokenization, fine-tuning
- **When:** Month 4-5
- **Output:** Fine-tune a model end-to-end
- **Time:** ~30 hours

### 5. "Grokking the Coding Interview" / "Grokking the System Design Interview" (Educative)
- **Format:** Interactive web course
- **Why:** Pattern-based DSA + system design specifically for interviews
- **When:** Months 1-6
- **Output:** Pass mock interviews
- **Cost:** ~$60 (subscription)

## Course completion ratio

Standard "completion" rate for online courses: 10-15%.

Aim for: 80%+ on Tier 1 courses you start.

How:
- Don't start multiple at once
- Time-block in calendar
- Submit/complete exercises
- Forfeit if you realize it's not the right course (and don't lecture-guilt yourself)

---

## Cost optimization

- Most Tier 1 are free
- Coursera financial aid (apply, often approved)
- Educative subscription only for the months you use it
- Udemy: only buy on $10-20 sales

Don't pay $500 for a course someone tells you to. Most are free or low-cost.
